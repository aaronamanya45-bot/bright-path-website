# Bright Path Website

A simple three-page website built as part of a Web Development lesson.

## 📌 Project Features
- **Three linked pages:** Home, About, and Contact.
- **HTML Structure:** Headings, paragraphs, lists, images, a form, and a data table.
- **CSS Styling:** A consistent external stylesheet (`style.css`) and an inline CSS example.
- **Testing:** Verified to work smoothly in modern web browsers.
